# Nexus Arena

Nexus Arena is a full-stack gaming platform with account registration and login,
editable player profiles and settings, a dashboard, and a Fruit Frenzy game with
a registered-user leaderboard.

## Requirements

- Node.js
- npm

## Run locally

```sh
npm install
node app.js
```

Open [http://localhost:3000](http://localhost:3000). The server creates and
updates `arena.db` locally; that database and installed dependencies are not
included in the repository.
